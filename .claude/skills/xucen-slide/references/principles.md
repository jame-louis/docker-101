# 许岑 · 电影级设计原则（canonical reference）

> ⚠️ **归因提醒**：「对比 / 重复 / 对齐 / 亲密」四项基本原则出自 Robin
> Williams《写给大家看的设计书》，**并非许岑原创**。本技能以许岑的电影级原则
> 为主，吸收排版四原则作为纪律，但不要把四原则说成许岑的贡献。

**出处**：许岑（Xǔ Cén）——罗永浩"御用"幻灯片制作者，《征服世界的美学暴力——
"电影级"幻灯片设计方法论》（2016）。

## 核心思想

> 幻灯片不是给人读的文档，是给人看的电影——**被观看，而非被翻阅**。
> 讲者才是主角；银幕上只放"镜头"和"台词"，细节在讲者的嘴里。

## ⭐ 已验证：演讲稿先行（Speech-First）

许岑的规范工作流程（《配合一套幻灯片演讲的流程》/《征服世界的美学暴力》目录）：

1. **从写逐字稿开始**——根据发言内容（文字稿）确定幻灯片内容；
2. 设定幻灯片**比例与背景深浅**（区分 LED 屏与幕布/投影）；
3. 根据逐字稿**准备素材**（文字、数据、图片、视频）；
4. **演练并修改**。

配套理念：**幻灯片上已有的内容不要重复讲**——银幕与口播互补：
银幕出关键词/镜头/数据，口播出完整句与解释。

> ⚠️ 例外：锤子发布会"边讲边做 PPT"是赶工轶事，非规范流程。

## 原则（附每镜翻译）

| 原则 | 含义 | 在一张幻灯片上 |
|---|---|---|
| **演讲稿先行** | 先写逐字稿，再设计幻灯片；内容（讲的话）决定设计 | 幻灯片由文字稿"抽帧"而来 |
| **银幕不重复口播** | 幻灯片与口播互补，不重复 | 银幕已写的，嘴里不念；嘴里讲的，银幕只给关键词 |
| **电影级（被观看）** | 幻灯片像电影一帧帧流过，不靠"读完"理解，靠"看见"感受 | 一句话能看懂；不是一段话才能看懂 |
| **分镜 / 三幕剧** | 内容按剧作结构组织：片头钩子 → 起承转合 → 高潮 → 片尾彩蛋 | 全片有"片头 / 三幕 / 片尾"；每幕有幕卡 |
| **台词式标题（每镜一话）** | 每张幻灯片是一句"台词"，不是主题词 | 标题是一句话，不是名词标签；如"每一层都安全，不等于整体安全" |
| **留白** | 空白是设计元素，不是待填充的空洞 | 可见内容 ≤ 1 句台词 + ≤3 个要点（≤ ~6 行 / ~200 字） |
| **一致性与完整性** | 全片同一部电影：幕卡同构、粗体只加一次、节奏统一 | 幕卡模板重复；关键词粗体一次；同一列表/引注样式 |
| **次序（sequence）** | 信息有层级与推进，制造悬念与节奏 | 编号、时间线、递进（①→⑦、防线①→⑤） |
| **图片即镜头** | 图片不是插图，是"大镜头" | 全出血大图或 `image-right`；图注一句话 |
| **动画 / 神奇移动** | 切换制造"摄像机"的连续感，形成个人风格 | 幕卡淡入、内容推移；"连续缩放"式转场；`v-clicks` 逐条揭示 |
| **越用心越美好** | 细节的考究本身就是价值 | 转场、节奏、收尾都精心设计；不留粗糙痕迹 |
| **内容决定设计** | 设计为内容服务，不炫技 | 每个"镜头"都服务于知识要点，不为了美而牺牲准确 |

> 排版四原则（Robin Williams，《写给大家看的设计书》）作为纪律补充：
> **对比**强调关键、**重复**统一视觉、**对齐**建立秩序、**亲密**归组信息。
> 生搬时勿悬置于许岑之上。

## 镜头类型（在讲者备注中标注）

| 类型 | 用途 | 示例 |
|---|---|---|
| 【空镜】 | 氛围 / 悬念 / 片头片尾 | 开场钩子、思考题、致谢 |
| 【全景】 | 总览 / 建立世界观 | 三特征、七道裂缝、五道防线 |
| 【特写】 | 单点深入 | 每个特征的独立镜头 |
| 【转场】 | 幕卡 / 章节切换 | 第一幕 · 万物相连 |

## 文字密度阈值（留白的操作性定义）

- 可见内容 ≤ ~6 行 且 ≤ ~200 字符（含标题、要点、一句图注）。
- 超过即触发 `scripts/audit-shots.py` 的 DENSE 标记 → 把细节下放到讲者备注。
- 例外：`> 引用`、表格行、LaTeX 公式、代码/图注可合理超长——它们本身就是"镜头"。

## 讲者备注（细节的家）

- 每镜必须有 `<!-- 讲者备注 -->`：`【镜头类型】+ 细节 + 教学提示`。
- 可见面被删掉的每一句完整内容，都必须能在备注中找到（**永不丢失内容**）。
- 转 Slidev 后，HTML 注释自动成为 presenter notes，无需二次搬运。
