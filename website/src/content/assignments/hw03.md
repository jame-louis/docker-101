## 作业目标

完成两次镜像相关的动手实践，体会**镜像分层**与**镜像生命周期**这两个核心概念。

## 作业要求

### 实战一：拉取并解剖一个镜像

**第 1 步：拉取官方 hello-world 镜像**

```bash
docker pull hello-world
```

**第 2 步：运行它**

```bash
docker run --rm hello-world
```

> `--rm` 表示退出后自动删除容器。

**第 3 步：拉取一个真实的基础镜像**

```bash
docker pull alpine:3.20
```

**第 4 步：用 docker history 看层**

```bash
docker history alpine:3.20
```

**第 5 步：用 docker inspect 看元数据**

```bash
docker inspect alpine:3.20
docker inspect alpine:3.20 --format '{{.Architecture}}'
```

**第 6 步：观察镜像大小与共享**

```bash
docker images
docker pull nginx:alpine          # 拉一个同样基于 Alpine 的镜像，再次体会层共享
```

### 实战二：从容器创建你的第一个镜像

**第 1 步：启动一个交互式容器**

```bash
docker run -it --name myubuntu ubuntu:22.04 /bin/bash
```

**第 2 步：在容器里做点"修改"**

```bash
apt-get update && apt-get install -y curl
apt-get install -y vim
exit          # 退出容器（容器停止，但不删除）
```

**第 3 步：用 docker commit 把修改保存为镜像**

```bash
docker commit myubuntu myubuntu:with-tools
```

**第 4 步：验证新镜像**

```bash
docker images          # 多出了 myubuntu:with-tools
docker history myubuntu:with-tools
```

**第 5 步：tag 来表示发布版本**

```bash
docker tag myubuntu:with-tools <你的用户名>/myubuntu:v1
```

**第 6 步：导出为离线文件（save）**

```bash
docker save -o myubuntu.tar <你的用户名>/myubuntu:v1
ls -lh myubuntu.tar
```

**第 7 步：删除并重新导入（rmi → load）**

```bash
# 先删除所有引用此镜像的容器，再删除镜像
docker rm myubuntu
docker rmi myubuntu:with-tools <你的用户名>/myubuntu:v1
docker images                          # 确认已删除

# 从 tar 文件恢复
docker load -i myubuntu.tar
docker images                          # 镜像回来了
```

> 正式项目请用 Dockerfile 构建镜像，`docker commit` 仅用于理解"镜像从无到有"的过程。
