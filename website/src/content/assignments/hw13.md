## 作业目标

下载 **Tomcat** 镜像，将一段 Java Web 工程（Servlet）**打包成 war 文件**并构建容器，最后运行镜像并**验证该应用是否在容器中正常运行**——完成课程收官实战。

## 作业要求

### 实战：Tomcat 部署 Java Web 的 war

**第 1 步：下载 Tomcat 镜像**

```bash
docker pull tomcat:10
```

**第 2 步：准备一个 Java Web 工程并打成 war（可用第 15 讲的最简 Servlet）**

按 `WEB-INF` 结构摆放并打包：

```bash
# 假定已编译出 HelloServlet.class, 并按以下结构组织
# build/
#   WEB-INF/
#     web.xml
#     classes/com/example/HelloServlet.class
cd build && jar cvf ../javademo.war . && cd ..
jar tf javademo.war          # 确认有 WEB-INF/web.xml
```

（若你更习惯 Maven，也可用 `mvn package` 产出 war。）

**第 3 步：创建 Dockerfile 并构建容器**

```bash
echo 'FROM tomcat:10' > Dockerfile
echo 'COPY javademo.war /usr/local/tomcat/webapps/javademo.war' >> Dockerfile
docker build -t java-web .
```

**第 4 步：运行镜像并验证是否正常运行**

```bash
docker run -d --name jweb -p 8080:8080 java-web
docker ps | grep jweb                    # 状态 Up
curl http://localhost:8080/javademo/hello   # 返回 Servlet 页面 = 正常
docker logs jweb | grep -i deploy        # 看到 Deployed
docker exec -it jweb ls /usr/local/tomcat/webapps/   # 看到 javademo
```
