## 作业目标

创建一个**数据卷**并将容器目录挂载到该卷上，同时把一个**宿主机目录**绑定挂载进容器，最后使用 `docker volume inspect` 查看数据卷的具体信息，理解"数据在容器之外、容器删除数据仍在"。

## 作业要求

### 实战一：数据卷让数据跨容器存活

```bash
docker volume create webdata
docker run -d --name site1 -v webdata:/usr/share/nginx/html -p 8081:80 nginx
docker exec -it site1 bash -c 'echo persist > /usr/share/nginx/html/p.txt'
curl http://localhost:8081/p.txt        # 能访问 persist

# 删容器, 再挂同一卷重建
docker rm -f site1
docker run -d --name site2 -v webdata:/usr/share/nginx/html -p 8082:80 nginx
curl http://localhost:8082/p.txt        # persist 还在
```

### 实战二：绑定挂载一个宿主机目录

```bash
mkdir -p ~/dev/demo
echo '<h1>Demo site</h1>' > ~/dev/demo/index.html

docker run -d --name dev -p 8080:80 \
  -v "$HOME/dev/demo":/usr/share/nginx/html nginx
curl http://localhost:8080/            # 看到 Demo site

# 改宿主机文件, 容器内立即生效
echo '<h1>Updated!</h1>' > ~/dev/demo/index.html
curl http://localhost:8080/            # 变成 Updated!
```

### 查看数据卷信息

```bash
docker volume inspect webdata
# 输出里注意 Mountpoint 字段(数据卷在宿主机上的真实存储位置)
docker volume ls
```

请指出 `docker volume inspect webdata` 输出中的 **Mountpoint** 对应的具体路径，并说明它的含义。
