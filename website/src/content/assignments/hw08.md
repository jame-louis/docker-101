## 作业目标

实现一个 **Java 程序的 Docker 部署**：用 **Maven 多阶段构建**把源码打成 jar，再用 `eclipse-temurin:17-jre` 运行；并通过 `ENV` 环境变量控制程序行为，体验"镜像中固化环境、运行时覆盖环境"。

## 作业要求

### 实战：部署一个读环境变量的 Java 程序

**第 1 步：建目录与最小 Maven 工程**

```bash
mkdir -p java-demo/app && cd java-demo
```

`app/pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
  <modelVersion>4.0.0</modelVersion>
  <groupId>demo</groupId>
  <artifactId>app</artifactId>
  <version>1.0</version>
  <packaging>jar</packaging>
  <build><finalName>app</finalName></build>
</project>
```

`app/src/main/java/demo/Hello.java`：

```java
package demo;
public class Hello {
    public static void main(String[] a) {
        String who = System.getenv().getOrDefault("WHO", "world");
        System.out.println("Hello " + who + " from Java!");
    }
}
```

**第 2 步：写多阶段 Dockerfile**

```dockerfile
FROM maven:3.9-eclipse-temurin-17 AS build
WORKDIR /build
COPY pom.xml .
RUN mvn dependency:go-offline
COPY src ./src
RUN mvn package -DskipTests

FROM eclipse-temurin:17-jre
ENV WHO=world
WORKDIR /app
COPY --from=build /build/target/app.jar app.jar
CMD ["java", "-jar", "app.jar"]
```

**第 3 步：构建并运行**

```bash
cd app
docker build -t hello-java .
docker run --rm hello-java              # Hello world from Java!
docker run --rm -e WHO=Docker hello-java # Hello Docker from Java!
```

**第 4 步：观察镜像分层与大小**

```bash
docker images | grep hello-java          # 很精简的 jre 镜像(不含 Maven/源码)
docker history hello-java                # 看镜像分层; build 阶段的编译产物并未进入最终镜像
```
