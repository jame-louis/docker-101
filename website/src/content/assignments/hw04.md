## 作业目标

通过两次容器动手实践，直观理解**容器生命周期**、**容器之间的隔离**，以及**容器数据默认不持久**这一关键痛点。

## 作业要求

### 实战一：跑起你的第一个应用容器

**第 1 步：拉取镜像**

```bash
docker pull nginx:latest
```

**第 2 步：前台快速运行并观察**

```bash
docker run nginx:latest
```

> 终端被"占住"（前台运行）。按下 `Ctrl+C` 会向容器发送停止信号。

**第 3 步：后台运行 + 端口映射 + 命名**

```bash
docker run -d --name myweb -p 8080:80 nginx:latest
```

**第 4 步：验证容器正在运行**

```bash
docker ps
```

看到名为 `myweb`、PORTS 为 `0.0.0.0:8080->80/tcp`、STATUS 为 `Up ...` 的容器即为成功。

**第 5 步：访问容器提供的网页**

```bash
curl http://localhost:8080
```

应返回 nginx 的默认欢迎页 HTML。

**第 6 步：查看日志**

```bash
docker logs myweb
```

**第 7 步：进入容器内部探一探**

```bash
docker exec -it myweb /bin/bash
```

进入后执行下面几条命令，感受"容器像台小机器"：

```bash
ls /usr/share/nginx/html     # 容器网站根目录
hostname                     # 返回容器 ID
ps aux                       # 只看到容器内的进程
cat /etc/os-release          # 容器内基于的系统（debian）
exit                         # 退出，容器继续运行
```

**第 8 步：停止并删除**

```bash
docker stop myweb
docker ps              # 列表里已没有它（停止的不显示）
docker ps -a           # 以 Exited 状态出现在这里
docker rm myweb        # 真正删除
docker images          # 镜像还在
```

### 实战二：两个容器互不干扰 + 数据持久化

**第 1 步：用同一个 nginx 镜像启动两个容器**

```bash
docker run -d --name site1 -p 8081:80 nginx
docker run -d --name site2 -p 8082:80 nginx
docker ps
```

**第 2 步：进入 site1 修改页面，验证 site2 不受影响**

```bash
docker exec -it site1 /bin/bash
echo "Hello from site1" > /usr/share/nginx/html/index.html
exit
curl http://localhost:8081    # 显示 Hello from site1
curl http://localhost:8082    # 仍是默认首页（隔离）
```

**第 3 步：发现痛点——容器数据不持久**

```bash
docker rm -f site1 site2
docker run -d --name site1 -p 8081:80 nginx
curl http://localhost:8081    # 刚才改的内容没了，回到默认页
```

**第 4 步：用数据卷（Volume）持久化**

```bash
docker volume create webdata
docker run -d --name site1 -v webdata:/usr/share/nginx/html -p 8081:80 nginx

docker exec -it site1 /bin/bash
echo "Persistent!" > /usr/share/nginx/html/index.html
exit

docker rm -f site1            # 删容器，卷还在
docker volume ls              # webdata 仍在

# 用同一个卷再开一个容器，数据回来了
docker run -d --name site2 -v webdata:/usr/share/nginx/html -p 8082:80 nginx
curl http://localhost:8082    # 显示 Persistent! —— 数据跨容器存活
```

**第 5 步：清理现场**

```bash
docker rm -f site1 site2
docker volume rm webdata
```
