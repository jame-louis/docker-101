## 作业目标

完成镜像仓库的两次实战，掌握向 **Docker Hub 推送镜像** 与 **搭建并使用本地私有仓库**，理解镜像全名与仓库地址的关系。

## 作业要求

### 实战一：推送一个镜像到 Docker Hub

**第 1 步：准备镜像（用上讲的 Flask 示例）**

```bash
cd demo
docker build -t flask-demo:1.0 .
docker images          # 确认有 flask-demo:1.0
```

**第 2 步：登录 Docker Hub**

```bash
docker login
```

输入你的 Docker Hub 账号密码，看到 "Login Succeeded" 即为成功。

**第 3 步：打上自己的命名空间标签**

```bash
docker tag flask-demo:1.0 <你的用户名>/flask-demo:1.0
docker images          # 出现带用户名的条目，与 flask-demo:1.0 是同一镜像 ID
```

**第 4 步：推送**

```bash
docker push <你的用户名>/flask-demo:1.0
```

看到每层 `Pushed` 并输出 digest 即成功。

**第 5 步（可选）验证：拉回一个干净副本**

```bash
docker rmi <你的用户名>/flask-demo:1.0     # 删掉本地，模拟"没有它"
docker pull <你的用户名>/flask-demo:1.0    # 从 Docker Hub 重新拉取
docker run -d -p 5000:5000 <你的用户名>/flask-demo:1.0
```

### 实战二：搭建并使用本地私有仓库

**第 1 步：启动本地仓库容器**

```bash
docker run -d --name myregistry -p 5000:5000 \
  -v /opt/registry:/var/lib/registry registry:2
```

**第 2 步：确认仓库服务正常**

```bash
docker ps
curl http://localhost:5000/v2/          # 返回 {} 即服务正常
curl http://localhost:5000/v2/_catalog  # 当前返回 {}（还没镜像）
```

**第 3 步：准备一个待推送的镜像**

```bash
docker pull alpine:3.20
docker tag alpine:3.20 localhost:5000/alpine:3.20
docker images         # 看到 localhost:5000/alpine:3.20
```

**第 4 步：推送到本地仓库**

```bash
docker push localhost:5000/alpine:3.20
curl http://localhost:5000/v2/_catalog
```

`_catalog` 输出 `"repositories":["alpine"]`——镜像已经进到本地仓库。

**第 5 步：删掉本地镜像，再从仓库拉回（验证闭环）**

```bash
docker rmi localhost:5000/alpine:3.20 alpine:3.20
docker images         # alpine 相关都没了
docker pull localhost:5000/alpine:3.20   # 从本地仓库拉取
docker run --rm localhost:5000/alpine:3.20 echo "hello from local registry"
```

**第 6 步：体验数据持久化**

```bash
docker rm -f myregistry                 # 删掉仓库容器（服务停）
docker run -d --name myregistry -p 5000:5000 \
  -v /opt/registry:/var/lib/registry registry:2     # 用同一卷重建仓库
curl http://localhost:5000/v2/_catalog              # alpine 还在！数据靠卷幸存
```

**第 7 步：清理现场（可选）**

```bash
docker rm -f myregistry
sudo rm -rf /opt/registry                # 若确认不再需要数据卷内容
```
