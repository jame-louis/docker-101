## 作业目标

实现一个带第三方依赖的 **Python Web 应用（Flask）的 Docker 部署**：用官方 `python:3.12-slim` 镜像、`requirements.txt` 安装依赖、并通过 `host="0.0.0.0"` + `-p` 端口映射让外部能够访问。

## 作业要求

### 实战：部署一个 Flask Web 应用

**第 1 步：建目录**

```bash
mkdir -p py-demo && cd py-demo
```

**第 2 步：三个文件**

`requirements.txt`：

```
Flask==3.0.0
```

`app.py`：

```python
from flask import Flask
app = Flask(__name__)
@app.route("/")
def home():
    return "<h1>Hello Flask from Docker</h1>"
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

`Dockerfile`：

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]
```

**第 3 步：构建并访问**

```bash
cd py-demo
docker build -t flask-app .
docker run -d -p 5000:5000 --name flk flask-app
curl http://localhost:5000        # 看到 Hello Flask from Docker
docker logs flk                   # 看 Flask 访问日志
```

**第 4 步（体验层缓存）：再次构建**

```bash
docker build -t flask-app .
# requirements.txt 和依赖没变 → pip install 那一步命中缓存, 秒过
# 若你改写 app.py 后再 build, 注意哪一层被重建、哪一层被复用
```
